# Sales Data Analyzer & Visualization

A Python project that analyzes sales data and creates visualizations
using Pandas, NumPy, Matplotlib, and Seaborn.

## About the Project

This project helps users explore, clean, analyze, and visualize
sales data through a simple menu-driven interface.

It uses basic Python and Object-Oriented Programming (OOP)
concepts to perform different data analysis operations.

## Features

- Load sales data from a CSV file
- Explore and clean the dataset
- Calculate total, average, minimum, and maximum sales
- Calculate median, variance, and standard deviation
- Search, sort, and filter sales records
- Group sales data by region
- Perform NumPy array operations
- Generate pivot tables
- Create different sales charts
- Export analyzed data to a CSV file

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
